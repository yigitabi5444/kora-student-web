# Kora Aerospace Student Team

This is the site for student.kora-aerospace.com, in English and Turkish. It is plain HTML and CSS without a build step, and GitHub Pages serves it from `main`.

The Turkish pages are static copies in `tr/`. When you change a page, change its copy in the other language too.

To run it locally, start `python3 -m http.server 8080` in this folder and open http://localhost:8080.

These files are copies from the `design/` folder of the monorepo: `tokens.css` comes from `design/tokens.css`, `media/logo.svg` from `design/logos/kora-student-team-on-dark.svg`, and `favicon.ico`, `favicon.svg` and `apple-touch-icon.png` from `design/logos/favicon/`. The hero photo is `design/media/photos/fc-board-angle.jpg`, resized to 1240 px. `media/og.jpg` is the same photo cropped to 1200 by 630 px for link previews. Copy them again when the design changes.

The fonts in `fonts/` and the license texts in `LICENSES/` are the same files the company site uses.
