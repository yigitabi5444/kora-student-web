# Kora Aerospace Student Team

This is the site for student.kora-aerospace.com. It is plain HTML and CSS without a build step, and GitHub Pages serves it from `main`.

To run it locally, start `python3 -m http.server 8080` in this folder and open http://localhost:8080.

Three files are copies from the `design/` folder of the monorepo: `tokens.css` comes from `design/tokens.css`, `media/logo.svg` from `design/logos/kora-student-team-light.svg` and `favicon.svg` from `design/logos/kora-icon-green.svg`. Copy them again when the design changes.

The fonts in `fonts/` and the license texts in `LICENSES/` are the same files the company site uses.
