# Kora Aerospace Student Team

Site for student.kora-aerospace.com. Plain HTML and CSS, no build step, served by GitHub Pages from `main`.

- Run locally: `python3 -m http.server 8080` here, then open http://localhost:8080.
- Design copies from the monorepo `design/` folder: `tokens.css` = `design/tokens.css`, `media/logo.svg` = `design/logos/kora-student-team-light.svg`, `favicon.svg` = `design/logos/kora-icon-green.svg`. Copy them again when the design changes.
